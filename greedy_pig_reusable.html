⚙ Class list & game setup — paste names or upload a .txt/.csv file

One student per line (e.g. Chan Hilary). You can paste directly below, or choose a plain-text / CSV file. For CSV, use a single column of names; a header such as Name is optional. Changing the class list starts a fresh game, so export your current scores first.

Names are saved locally in this browser, along with game progress. The HTML file works offline. A different browser or computer will not automatically have your saved classes.
